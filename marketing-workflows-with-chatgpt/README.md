## The case

New York Minute imagines an artist collaboration with The Fifth Avenue Hotel, followed by a consumer wallpaper collection. Broadway Backstage, Stories on the Streets, and Five Minutes on Fifth Ave are proposed designs. Times Square and Vogue Living are campaign mockups, not actual placements or partnerships. All campaign visuals here are AI-generated concepts. The notebook image records the author's original brainstorming.

## Use this kit

Pick one skill in `skills/`. Supply a brief and ask ChatGPT to follow that file for the current task. This manual method is a document-guided workflow; uploading a file alone does not install an automatically discovered skill. For supported skill installation, see the current official [Build skills guide](https://learn.chatgpt.com/docs/build-skills). In a supported Codex repository, place the selected folder under `.agents/skills/`. This kit does not install tools, connect accounts, or create an autonomous agent.

Every skill produces a reviewable draft or analysis. Keep external actions within the user's authorization. Launch-stage skills are drafts, not a claim of validated campaign results. Never treat synthetic reactions as real consumers or generated process imagery as proof of handmade production.

## Repository structure

`skills/` contains 12 instruction files. `templates/` contains editable blank working documents and CSV schemas. `guides/` explains reuse and evaluation. `presentation/` contains the talk, script, and slide text. `assets/` contains the illustrated case materials. No API key is required to read or reuse the instructions.
