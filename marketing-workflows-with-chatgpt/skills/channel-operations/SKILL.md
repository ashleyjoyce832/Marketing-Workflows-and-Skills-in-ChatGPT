# Channel Operations

## Inputs
Approved brief, current product facts, asset versions, channel roles, calendar/time zone, owners, and authorization. Reconcile conflicting versions before scheduling recommendations.

## Workflow
Assign each placement a purpose, asset ID, CTA, destination, tracking ID, owner, and status. Adapt copy and format to the channel while preserving the proposition. Check stock, price, dates, link behavior, accessibility text, and partner status.

Triage incoming questions into answerable from approved facts, needs product owner, or needs sensitive handling. Draft responses without inventing commitments. Log recurring questions for the evidence skill and future lifecycle content.

## Output and checks
Return the publication/response queue, unresolved issues, owners, and next review date. Drafting a calendar does not publish it. Execute external posts, messages, or spend changes only within explicit authorization and available tool controls. Do not re-request permissions already granted for the same scope.
