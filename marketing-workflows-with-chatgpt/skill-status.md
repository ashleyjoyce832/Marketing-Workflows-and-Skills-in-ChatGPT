## Changes from the starter files

- Concept expansion accepts one idea and does not require a criticism in every output.
- Ad adaptation starts with references and distinguishes exploration from a controlled test.
- Synthetic critique removes arbitrary sample thresholds and unsupported numerical bias correction.
- Tracking no longer calls organic channels test groups or assumes link services are free.
- Performance analysis checks data before explaining differences and allows an inconclusive result.
- Five new skills cover evidence synthesis, experiments, channel operations, launch review, and skill evaluation.

Use the supplied evaluation template before relying on these files in a real workflow. No independent behavioral evaluation has been performed for this revision.
