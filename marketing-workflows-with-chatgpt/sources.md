# Readings and evidence

Checked September 28–29, 2026. Quotes are short excerpts; consult the original before quoting more. Page references for the creativity article use its printed page numbering. No full source PDF is redistributed.

## Foundation

1. OpenAI Academy. *ChatGPT for marketing teams* (April 10, 2026). https://openai.com/academy/marketing/ — Foundation for the assignment: campaign planning, reusable work, image concepts, and performance analysis. A short excerpt for discussion: “Apply human judgment for final decisions.” Section: How teams use ChatGPT effectively. The case study did not measure the productivity benefits described on this page.
2. OpenAI Academy. *Using skills* (April 10, 2026). https://openai.com/academy/skills/ — Describes repeatable procedures, inputs, output formats, and checks. Quotation used on slide 6: “A skill is a reusable, shareable workflow”. Section: What are skills?
3. Boussioux, L., Doshi, A., Hauser, O., & Hosanagar, K. *The Hidden Cost of AI-Assisted Creativity*. MIT Sloan Management Review, July 9, 2026, reprint 68108. https://doi.org/10.63383/sXIt9497 — Read from Ashley's supplied PDF. Quote used on slide 2: “Keep humans in the driver’s seat for ideation.” Page 4. The article synthesizes four studies and distinguishes individual output quality from collective diversity. It supports deliberate workflow sequencing, not a universal claim that AI lowers all creative quality.

## Implementation

4. OpenAI. *Build skills*. https://learn.chatgpt.com/docs/build-skills — Checked for file structure and current product-specific discovery and distribution guidance. Installing a skill and uploading a reference document are different operations.
5. OpenAI Academy. *ChatGPT Work for marketing teams: Webinar Resource Guide* (August 26, 2026). https://academy.openai.com/public/clubs/work-users-ynjqu/resources/chatgpt-work-for-marketing-teams-webinar-resource-guide-2026-08-26 — Additional workflow design context for marketing preparation and review.
6. Anthropic. *Building Effective AI Agents*. https://www.anthropic.com/engineering/building-effective-agents — Distinguishes predefined workflow patterns from systems that dynamically control execution. This project used a human-led workflow, not a deployed autonomous marketing agent.
7. OpenAI Academy. *Workspace agents*. https://openai.com/academy/workspace-agents/ — Context for recurring work with approved tools. No agent was deployed for the campaign.
8. OpenAI. *Guardrails and human review*. https://developers.openai.com/api/docs/guides/agents/guardrails-approvals — Provides implementation context for separating automatic checks from action approval. The repository translates the distinction into marketing review boundaries.
9. OpenAI. *Evaluate agent workflows*. https://developers.openai.com/api/docs/guides/agent-evals — Supports saving representative cases and rerunning evaluations after changes. The lightweight evaluation template is a proposed adaptation, not an API-based eval implementation.

## Campaign measurement

10. Google. *Modern Measurement Playbook*. https://www.thinkwithgoogle.com/_qs/documents/18403/For_pub_on_TwG___External_Playbook_Modern_Measurement_bmzqiud.pdf — Pages 14–17 discuss combining attribution and incrementality (PDF page numbers 14–17 as displayed). Supports distinguishing reported response from causal impact. This kit does not assume a small pilot has enough data for advanced modelling.
