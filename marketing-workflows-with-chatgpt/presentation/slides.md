## 9. Appendix: the tools serve different roles

Project  /  Campaign context and files
Chat  /  Discussion and iteration
Skill  /  Instructions for a repeatable task
Agent  /  A system that can choose actions and use tools

A skill file alone does not schedule work or connect accounts.

## 10. Building a skill in chat

1  Run one real task with an approved brief
2  Correct the draft and record why
3  Distill the reusable steps into SKILL.md
4  Try a new case and a difficult case
5  Keep a version and a failure log

A creator can draft the file. People still evaluate its behavior.

## 13. Testing the campaign

Question: which message earns sample requests?
Change: copy angle only; hold the creative fixed
Design: random assignment where feasible
Decision: sufficient data, uncertainty, and a guardrail

Organic channel comparisons are observational. Simulated reactions are exploratory.
